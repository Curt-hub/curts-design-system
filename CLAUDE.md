# Curt's Design System — Agent & Developer Guide

CDS is a token-first design system template targeting Web (Next.js docs) and Flutter.
This file tells you where everything lives and how to consume it.

---

## What's in this repo

| Path | What it is |
|------|------------|
| `src/` | Next.js 14 documentation site |
| `src/lib/tokens.ts` | TypeScript source of truth for all token values |
| `tokens.json` | DTCG-format token export — consumable without a JS runtime |
| `specs/` | Machine-readable JSON specs + `index.json` registry |
| `CDS-Flutter/` | Flutter Dart token package (`package:cds`) |
| `public/snapshots/` | Per-state PNG screenshots (generated by `npm run snapshots`) |

## Token system

### Two tiers

1. **Palette** (`palette` const, not exported) — raw hex values. Never reference in components.
2. **Semantic tokens** (exported) — role-based names. Use these everywhere.

```
colors.brand          → #000000   TODO: set your brand color
colors.background     → #FFFFFF   (dark: colors.backgroundDark)
colors.onBackground   → #000000   (dark: #FFFFFF)
colors.success        → #16C172
colors.error          → #F03A47
```

### Files

| File | Purpose |
|------|---------|
| `src/lib/tokens.ts` | TypeScript source of truth |
| `tokens.json` | DTCG-format export (regenerate: `npm run export-tokens`) |
| `CDS-Flutter/lib/tokens/cds_colors.dart` | Flutter color tokens |
| `CDS-Flutter/lib/tokens/cds_spacing.dart` | Flutter spacing tokens |
| `CDS-Flutter/lib/tokens/cds_radius.dart` | Flutter radius tokens |
| `CDS-Flutter/lib/tokens/cds_typography.dart` | Flutter typography tokens |
| `CDS-Flutter/lib/tokens/cds_shadows.dart` | Flutter shadow tokens |

Key constraint: **all colours and spacing in components reference semantic token names, never
raw hex values.** Map any hex you see in designs back to a token before using it.

### Token categories

| Export | Keys |
|--------|------|
| `colors` | brand, background*, onBackground*, outline*, success/error/warning/info |
| `spacing` | xs(4) sm(8) md(12) lg(16) xl(20) 2xl(24) 3xl(32) 4xl(40) 5xl(48) |
| `radius` | sm(6) md(12) lg(16) xl(24) full(9999) |
| `shadows` | bottomA-D, topA-D, sideNav, tilesActive, tilesHover |
| `typography` | fontFamily (placeholder), sizes (supporting/body/section/title/hero), weights |

### Regenerating tokens.json

```bash
npm run export-tokens
```

## How to consume — Flutter

```dart
import 'package:cds/cds.dart';

Text('Hello', style: CDSTypography.body)
Container(color: CDSColors.brand)
SizedBox(height: CDSSpacing.md)
ClipRRect(borderRadius: CDSRadius.brMd)
DecoratedBox(decoration: BoxDecoration(boxShadow: CDSShadows.bottomC))
```

**Verify the build:**

```bash
cd CDS-Flutter && flutter pub get
```

## How to consume — Web

import { colors, spacing, radius, shadows, typography } from '@/lib/tokens';

## Customising for a new brand

1. `src/lib/tokens.ts` — set `palette.brand` and `palette.darkSurface` hex values
2. `CDS-Flutter/lib/tokens/cds_colors.dart` — update `_Palette.brand` and `_Palette.darkSurface`
3. `CDS-Flutter/lib/tokens/cds_typography.dart` — replace `'YourFont'` with your font family
4. `tailwind.config.ts` — update `brand` and `background-dark` color values
5. `src/app/layout.tsx` — swap `Poppins` import for your chosen font
6. Run `npm run export-tokens` to regenerate `tokens.json`
